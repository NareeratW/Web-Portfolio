Personal Portfolio Website

A futuristic, dark-themed personal portfolio website engineered to showcase professional skills, projects, and educational background. Featuring custom animated background glow lines, smooth transitions, and a fully interactive, scannable user interface.

Technologies Used
HTML5 CSS3 JavaScript (Vanilla) CSS Variables Custom CSS Animations Responsive Design
Key Responsibilities
  • Designed and structured a fully responsive layout ensuring flawless cross-platform rendering across Mobile, Tablet, and Desktop screens.
  • Implemented dynamic ambient background visuals using CSS `@keyframes` animations to create an immersive, high-tech user experience.
  • Maintained a componentized styling architecture using CSS variables for clean modularity, allowing site-wide themes to remain unified.
  • Optimized navigation behaviors with custom smooth-scrolling configurations and balanced content densities.
