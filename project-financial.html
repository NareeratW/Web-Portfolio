Web Application for Financial Integrity Learning among Students

Web application designed to promote financial integrity and literacy among university students. The platform delivers interactive learning modules, scenario-based assessments, and progress tracking mechanisms to cultivate responsible financial behaviors.

Technologies Used
Next.js React Node.js TypeScript PostgreSQL
Key Responsibilities
  • Developed a highly responsive and interactive frontend using React and Tailwind CSS to ensure a seamless user experience
  • Architected and deployed robust RESTful APIs using Node.js and Express.js for scalable backend services
  • Designed optimal database schemas and efficiently managed relational data persistence with PostgreSQL
  • Implemented secure user authentication workflows and password encryption mechanisms using bcrypt
  • Engineered interactive, gamified learning modules integrated with analytical pre-test and post-test evaluation systems
  • Created dynamic dashboards to streamline user statistics tracking and interactive data visualization
  • Conducted comprehensive API testing using Postman and managed source code version control via GitHub
