Automatic Thai License Plate & Province Recognition System

An intelligent Artificial Intelligence system designed to automatically detect, read, and classify Thai vehicle license plates. The system utilizes advanced computer vision and Deep Learning to localize license plates, extract alphanumeric characters, and accurately identify the registered province (supporting 76 provinces) from images or video streams.

Technologies Used
Python OpenCV YOLO / Deep Learning PyTorch / TensorFlow OCR (Optical Character Recognition)
Key Responsibilities & Features
  • Developed image preprocessing pipelines using OpenCV to optimize contrast, reduce noise, and handle diverse lighting conditions.
  • Implemented and fine-tuned object detection models (YOLO) to accurately localize license plate regions in complex scenes.
  • Engineered character segmentation and OCR algorithms specialized in recognizing Thai alphabets, digits, and stylized provincial text.
  • Mapped recognized text against dynamic datasets (`province_map.csv` and `vehicle_profiles.yaml`) to automatically classify vehicle usage type (e.g., private car, public transport, or auction plates).
  • Conducted rigorous system evaluation and optimized execution loops for real-time video stream inference.
  • Collaborated with a cross-functional development team utilizing Git and GitHub for structural version control.
