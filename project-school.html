School Management System

An enterprise-ready Full-Stack web application architected to streamline internal school administrations, academic curricula, and student tracking systems. Built on a server-optimized architecture utilizing state-of-the-art data rendering and strict session validation tools.

Technologies Used
Next.js 16 React 19 TypeScript Tailwind CSS Prisma ORM React Query Bcrypt.js Jose (JWT) Zod React to Print
Key Responsibilities
  • Architected core application patterns using Next.js App Router and React 19 for highly performant server-side processing and instant interface hydration.
  • Engineered strict authentication policies utilizing `bcryptjs` for granular credential hashing and `jose` for lightweight, cryptographic JWT token workflows.
  • Designed entity-relationship schemas and automated type-safe multi-table mutations through Prisma ORM.
  • Managed real-time server-state data sync, caching layers, and automated layout re-validations via TanStack React Query.
  • Enforced rigorous type-safety and endpoint input validation rules leveraging Zod schema engines to neutralize invalid payloads.
  • Implemented localized reporting features with `react-to-print` enabling instant conversion of data states into clean physical forms or documents.
