AI Agent "Nong Aew Nuea" (Northern Travel Guide)

An intelligent travel planning AI agent designed to assist users in discovering and scheduling trips across 9 northern provinces of Thailand. Operating 24/7 via LINE Official Account, the system dynamically analyzes user preferences, references real-time context, and structures itineraries automatically synchronized into Notion workspaces.

Technologies Used
Python Google ADK Gemini 2.0 Flash LINE OA API Notion API SQLite
Key Responsibilities
  • Engineered intelligent AI Agents using Google GenAI SDK (ADK) to dynamically analyze, reason, and respond to complex user requests
  • Integrated the LINE Messaging API to deploy a highly responsive, 24/7 autonomous chatbot system via LINE Official Account (OA)
  • Developed an automated trip planning engine that generates personalized travel itineraries, restaurant recommendations, and dynamic budget estimations
  • Connected the Notion API to enable seamless, automated synchronization and structured storage of travel plans directly into user workspaces
  • Utilized Model Context Protocol (MCP) to facilitate real-time weather data retrieval and extensible external tool integrations
  • Architected asynchronous session orchestration paradigms and complex, multi-tiered AI Agent workflow systems
  • Implemented structural error handling protocols and robust logging instrumentation for real-time monitoring, debugging, and system stability
